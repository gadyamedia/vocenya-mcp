# Contributing

This repository holds the public parts of Vocenya's MCP servers: the official MCP Registry entries, the Claude Code plugin and the setup instructions. The servers themselves are hosted by Vocenya and their code is not here.

- **Found a mistake** in a listing, a setup snippet or a directory entry? Open an issue with the "Listing correction" template.
- **A snippet doesn't work** in your MCP client? Open an issue with the client name and version and what you saw.
- **Pull requests** for typos and setup instructions for other clients are welcome. Keep them small, and never include API keys or customer data.
- **Security issues:** see [SECURITY.md](SECURITY.md). Do not open a public issue.

Product support for Vocenya accounts: info@gh-businesssolutions.com
